Multi-Agent RL — Level-Based Foraging with Obstacles

CTDE • MAPPO • Cooperation • Partial Observability

Abstract

This project studies cooperative multi-agent reinforcement learning in an obstacle-augmented Level-Based Foraging environment. Agents learn to coordinate under partial observability and spatial constraints using MAPPO under a centralized-training, decentralized-execution framework. Experiments vary field-of-view, obstacle density, and agent levels to evaluate learning stability and cooperation under bottlenecks.

Why it relates to robotics/autonomy

Multi-robot teams face occlusion, limited sensing, and shared resources. CTDE methods are useful because training can use global state, while deployment uses only local observations.
