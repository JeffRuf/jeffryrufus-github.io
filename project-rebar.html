Rebar-tying robot

Arn Autonomy (formerly Spacer Robotics) · San Francisco

A gantry robot that rides on a rebar grid and ties the crossings. I designed the chassis in SolidWorks, wrote the BOM, built the prototype, integrated the hardware and ran the tests.

RoleMechanical & Robotics Engineering Intern
PeriodMay to Aug 2025
ToolsSolidWorks, hand calculations, Python, YOLOv5
Frame2020 aluminum extrusion
01

Sizing the chassis

  • The 427 × 427 mm footprint came from the rebar grid spacing and the tool loads. The frame uses 2020 aluminum extrusions, drivetrain mounts and a guide-rail-stabilized linear actuator for the tying tool.
  • The first frame used heavy 4045 extrusions. Hand calculations showed stiffness, not strength, was the real limit.
  • Moving to 2020 and doubling only the guide-rail members made the robot 25% lighter while beam deflection stayed under 0.5 mm with a safety factor above 2 under a 2× dynamic load.

Building it

  • One fastener size across the build and standard extrusion hardware, so assembly is fast.
  • Gusset plates resist frame racking.
  • Wrote the BOM and built the prototype.
03

Testing it

  • Paired 30 Hz visual servoing with a 200 Hz PID loop for tool positioning.
  • Labeled 200+ crossings the robot missed in live grid runs and retrained YOLOv5. Crossing detection rose from under 50% to 90%.
