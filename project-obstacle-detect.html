Vector Coordinate Obstacle Detection (Ultrasonic + ToF)

Sensors • Geometry • Calibration • Embedded

Abstract

Designed a low-cost obstacle localization concept using range sensors. ToF sensors provide stable short-range distance estimates, while ultrasonic sensors extend range with a wider beam. With known sensor positions (or a swept sensor), range constraints can be used to infer obstacle coordinates in a local frame via triangulation or geometric fitting. Accuracy depends on beam width, surface reflectivity, and calibration.
